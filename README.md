# SocialHumanoid Project Page

This directory contains a static GitHub Pages project page for:

**SocialHumanoid: A Real-Time Speech-Driven System for Affective Humanoid Motion**

## Structure

- `index.html` - main project page
- `styles.css` - responsive page styling
- `script.js` - demo tabs, active navigation, and BibTeX copy behavior
- `.nojekyll` - keeps GitHub Pages from processing the site with Jekyll
- `static/figures/` - paper figures and result images
- `static/videos/` - robot demo videos

## Updating Links

The hero buttons for paper, arXiv, code, and dataset are currently marked as `(coming soon)`.
When final URLs are available, update the link area near the top of `index.html`.

## GitHub Pages

This is a no-build static page. GitHub Pages can serve it directly from the repository root.
